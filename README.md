# Poorly Planned — Downloads

Public Windows and macOS playtest builds of Poorly Planned, a cooperative heist game for 1–4 players.
The game source is maintained in a separate private repository. This repository contains download
instructions and release files.

- [All versions](https://github.com/mxs4751/PoorlyPlanned-Releases/releases)

The download links become available when the first release is published.

## Install and update

**Windows:** unzip into a folder and run `PoorlyPlanned.exe`. Keep the supporting files beside it.

**macOS:** extract `PoorlyPlanned.app`. These playtest builds are unsigned.

For updates, close the game and extract the new version into a fresh folder. Your saves are stored
outside the installation. Updates are manual downloads; there is no automatic updater.

Use the same release version as your crew for multiplayer. Each release includes `SHA256SUMS.txt`
with checksums for both archives. Older releases stay available on their versioned release pages.
